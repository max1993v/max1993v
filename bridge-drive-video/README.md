# Поїздка через міст — POV-відео

Вертикальне відео 1080×1920, 30 fps, ~15 с.

**Заставка (~5 с, `intro.py`)** — титульний екран гри NORTH BRIDGE (`assets/title.webp`): над мостом
пролітає шахед (намальований на картинці прибрано), напис переливається, внизу блимає START,
кнопка «натискається» — і піксельна мозаїка переходить у поїздку.

**Поїздка (10 с)** — вид із салону Audi,
машина їде дорогою, міст наближається, пілон проходить над головою.
Машина ледь помітно погойдується ступенями по «пікселю», як у 8-бітній грі,
а кермо разом із руками легенько повертається (до ~3°), і дорога трохи зміщується слідом.
У небі з інтервалом 2 с пролітають п'ять шахедів (`SHAHEDS` у `render.py`: час, висота, розмір, напрям).
Шахед вирізано з намальованої «шахівниці» скриптом `tools/cutout_shahed.py` → `assets/shahed.png`.

```bash
python3 render.py            # → out/bridge-drive.mp4 (потрібні Pillow, numpy, opencv-python-headless, ffmpeg)
python3 render.py --stills   # кілька контрольних кадрів у out/
```

Налаштування — константи вгорі `render.py`: `T` (тривалість), `Z_END` (як близько під'їжджаємо),
`steer()` (кут керма), `sway()` (погойдування), маски керма `OPENINGS`/`ARMS`, `COCKPIT_SHIFT` (наскільки опущено салон).
