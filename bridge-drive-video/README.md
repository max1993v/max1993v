# Поїздка через міст — POV-відео

Вертикальне відео 1080×1920, 30 fps, 10 с, зациклене: вид із салону Audi,
машина їде дорогою, міст наближається, пілон проходить над головою, легка тряска авто.

```bash
python3 render.py            # → out/bridge-drive.mp4 (потрібні Pillow, numpy, ffmpeg)
python3 render.py --stills   # кілька контрольних кадрів у out/
```

Налаштування — константи вгорі `render.py`: `T` (тривалість), `Z_END` (як близько під'їжджаємо),
`BUMPS` і `shake()` (сила тряски), `COCKPIT_SHIFT` (наскільки опущено салон).
