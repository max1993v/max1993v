# SNEAKER MAMA — моушн-відео для Reels

Процедурне вертикальне відео 9:16 (1080×1920, 30 fps, 23 с) з оригінальним
саундтреком, синтезованим кодом. Без стокових зображень, семплів і ліцензійної музики.

## Швидкий старт

```bash
npm run preview          # http://localhost:8080 — плеєр зі звуком (кнопка Play)
npm install              # один раз: Playwright для еталонного експорту
npm run export           # → out/sneaker-mama-reel.mp4 (H.264 High + AAC 48 кГц стерео)
npm run verify           # перевірка формату, тривалості, синхрону, LUFS і піку
```

Потрібні Node 18+ і `ffmpeg` у PATH. Для однакового з макетом шрифту встановіть
**Inter Display** (без нього підвантажиться Inter з Google Fonts).

У плеєрі також є кнопка **«Експорт MP4»**: кодування в браузері через WebCodecs
(Chrome / Edge), кадр за кадром, швидше за реальний час. Якщо браузер не має AAC-кодера,
аудіо буде в Opus — тоді для Instagram краще `npm run export`.

## Як це влаштовано

| Файл | Що робить |
|---|---|
| `src/scene.js` | `render(ctx, t)` — детермінована функція кадру за часом: фон, сцени, вайпи, постійний UI, кінозерно |
| `src/timeline.js` | Спільна таймлінія подій (бульбашки, ходи щітки, пшики, «поп» бактерій, відскоки крапель) — і картинка, і звук беруть час звідси |
| `src/audio.js` | Саундтрек на Web Audio API, рендер через `OfflineAudioContext` |
| `src/loudness.js` | Гучність за ITU-R BS.1770-4 (LUFS), лімітер, запис WAV |
| `src/app.js` | Плеєр (час береться з аудіо-годинника), експорт через WebCodecs, API для headless-рендера |
| `export/render.mjs` | Еталонний експорт: headless Chromium рендерить кадри тим самим `render(t)`, ffmpeg зводить з WAV |
| `export/verify.mjs` | Перевірка готового MP4 |
| `src/logo-paths.js` | Логотип (фігурка + написи), векторизований з `assets/logo-source.jpg` скриптом `tools/trace_logo.py` |

Уся випадковість — через seed (`mulberry32`), стану між кадрами немає: частинки, пил з
гравітацією, краплі з відскоком рахуються аналітично від `t`. Тому будь-який кадр
можна відрендерити окремо, і експорт стабільний покадрово.

## Звук

120 BPM (такт = 2 с), ля мінор. Зміни сцен (3, 7, 11, 15, 19 с) припадають на сильну долю.

- **0–3 с** пад Am9 + райзер з білого шуму → на 3 с удар бочки, саб і старт біту
- **Біт**: бочка (синус зі спадом висоти) на кожну долю, клеп з шуму на 2 і 4, хай-хети вісімками зі свінгом 10 %,
  бас-пилка через ФНЧ (рифом A–A–C–G), пад Am9 ↔ Fmaj7 з повільним фільтром і «пампінгом»
- **19–23 с**: біт зупиняється, пад іде в реверб, «дзинь» на появі кнопки сайту, фейд-аут за останні 1.5 с
- **Ефекти** з таймлінії: «пш-ш» на кожен вайп (панорама зліва направо), «пуф» бульбашок, шурхіт щітки
  (гучність і панорама йдуть за швидкістю і положенням щітки), 3 «пшики», «поп» кожної бактерії, «плінк» крапель

Музика й ефекти рендеряться окремими стемами: музика нормалізується до **−14 LUFS**, ефекти — до
**−20 LUFS** (на 6 дБ тихіше), потім сума проходить лімітер зі стелею −1.5 dBFS.
Результат останнього експорту: мікс −13.6 LUFS, true peak −1.0 dBTP.

## Контраст і безпечні зони

Перевіряється автоматично (виводиться в плеєрі та після `npm run export`):

| Пара | Контраст |
|---|---|
| графітовий текст / рожевий фон | 14.19:1 |
| другорядний текст / фон | 4.98:1 |
| малинові цифри, «MAMA» / фон | 4.77:1 |
| білий текст / малинова кнопка і вайп | 4.62:1 |
| теги: графіт / білий | 18.17:1 |

Акцент **#D6336C** як колір тексту на #F7DDE2 дає лише 3.6:1, тому для тексту на рожевому
використано глибший малиновий **#B8245A**. #D6336C лишився для графіки, вайпів, кнопки й логотипа-фігурки.

Важливий текст розміщено в межах 150 px від верху і 250 px від низу. Тонкий прогрес-бар —
декоративний елемент на 206 px від низу.
